# 📹 راهنمای ساخت ویدیو معرفی

این راهنما به شما کمک می‌کند تا ویدیو معرفی وب‌سایت Smart AI Trading Strategy Optimizer را بسازید.

---

## 🎯 گزینه‌های ساخت ویدیو

### **گزینه 1: استفاده از اسکریپت Python (ساده‌تر)**

این روش برای ساخت سریع یک ویدیو پایه مناسب است.

#### پیش‌نیازها:
```bash
pip install moviepy pillow numpy
```

#### اجرا:
```bash
cd scripts
python create_intro_video.py
```

#### نکات:
- ویدیو در `frontend/public/pro_vid.mp4` ذخیره می‌شود
- برای موسیقی، فایل `background_music.mp3` را در `frontend/public/` قرار دهید
- این روش یک ویدیو پایه می‌سازد. برای ویدیو حرفه‌ای‌تر از گزینه‌های دیگر استفاده کنید.

---

### **گزینه 2: استفاده از Canva Pro (توصیه می‌شود برای شروع سریع)**

Canva یک ابزار آنلاین است که ساخت ویدیو را آسان می‌کند.

#### مراحل:

1. **ثبت‌نام در Canva Pro** (یا استفاده از نسخه رایگان)

2. **ایجاد پروژه جدید**:
   - اندازه: 1920x1080 (Full HD)
   - نوع: Video

3. **استفاده از تمپلیت**:
   - جستجوی "Tech Introduction Video" یا "Product Launch Video"
   - انتخاب یک تمپلیت مناسب

4. **سفارشی‌سازی**:
   - جایگزینی متن‌ها با متن‌های فارسی از اسکریپت
   - تغییر رنگ‌ها به پالت رنگ برند
   - اضافه کردن لوگو و تصاویر وب‌سایت

5. **اضافه کردن موسیقی**:
   - استفاده از کتابخانه موسیقی Canva
   - جستجوی "Tech", "Corporate", "Energetic"

6. **صداگذاری** (اختیاری):
   - ضبط صدا با Canva Voice Recorder
   - یا استفاده از Text-to-Speech

7. **دانلود**:
   - فرمت: MP4
   - کیفیت: High (1080p)
   - ذخیره در `frontend/public/pro_vid.mp4`

---

### **گزینه 3: استفاده از Adobe After Effects (حرفه‌ای)**

این روش برای ساخت ویدیوهای بسیار حرفه‌ای با انیمیشن‌های پیشرفته مناسب است.

#### مراحل:

1. **نصب Adobe After Effects**

2. **ایجاد Composition جدید**:
   - Resolution: 1920x1080
   - Frame Rate: 30 fps
   - Duration: 35 seconds

3. **طراحی بخش‌ها**:
   - استفاده از اسکریپت ویدیو به عنوان راهنما
   - ایجاد لایه‌های جداگانه برای هر بخش
   - اضافه کردن انیمیشن‌ها (fade, scale, slide)

4. **اضافه کردن تصاویر وب‌سایت**:
   - گرفتن اسکرین‌شات از صفحات مختلف
   - اضافه کردن به composition
   - اضافه کردن انیمیشن‌های ورود/خروج

5. **افکت‌های ویژه**:
   - Particle effects برای نمایش AI
   - Glow effects برای دکمه‌ها
   - Chart animations برای نمودارها

6. **صداگذاری**:
   - اضافه کردن موسیقی پس‌زمینه
   - ضبط و اضافه کردن صدای گوینده
   - تنظیم سطح صدا

7. **رندر**:
   - Format: H.264
   - Quality: High
   - Resolution: 1920x1080

## ✅ چک‌لیست نهایی

قبل از انتشار ویدیو، این موارد را بررسی کنید:

- [ ] طول ویدیو بین 30-40 ثانیه است
- [ ] رزولوشن 1920x1080 است
- [ ] تمام متن‌ها واضح و خوانا هستند
- [ ] رنگ‌ها مطابق با پالت برند هستند
- [ ] موسیقی و صداگذاری با کیفیت مناسب است
- [ ] ویدیو در موبایل و دسکتاپ به خوبی نمایش داده می‌شود
- [ ] حجم فایل بهینه شده است (حدود 5-10 MB)
- [ ] فرمت MP4 با کیفیت بالا
- [ ] فایل در مسیر صحیح قرار دارد (`frontend/public/pro_vid.mp4`)

## 🚀 بهینه‌سازی برای وب

برای کاهش حجم فایل و بهبود بارگذاری:

1. **فشرده‌سازی ویدیو**:
   ```bash
   # استفاده از ffmpeg
   ffmpeg -i pro_vid.mp4 -vcodec libx264 -crf 28 -preset slow -acodec aac -b:a 128k pro_vid_compressed.mp4
   ```

2. **استفاده از WebM** (اختیاری):
   - فرمت WebM حجم کمتری دارد
   - پشتیبانی در مرورگرهای مدرن

3. **Lazy Loading**:
   - ویدیو باید با lazy loading بارگذاری شود (در Landing.tsx پیاده‌سازی شده)
