## 🚀 چگونه شروع کنیم؟

### **گزینه 1: استفاده از Canva (ساده‌ترین روش)**

1. به [Canva.com](https://www.canva.com) بروید و ثبت‌نام کنید
2. یک پروژه جدید با اندازه 1920x1080 ایجاد کنید
3. از اسکریپت در `docs/video_script_introduction.md` استفاده کنید
4. متن‌ها و رنگ‌ها را مطابق با راهنما تنظیم کنید
5. موسیقی از کتابخانه Canva اضافه کنید
6. ویدیو را دانلود کرده و در `frontend/public/pro_vid.mp4` ذخیره کنید

### **گزینه 2: استفاده از اسکریپت Python**

```bash
# نصب وابستگی‌ها
pip install -r scripts/requirements_video.txt

# اجرای اسکریپت
cd scripts
python create_intro_video.py
```

**نکته**: این روش یک ویدیو پایه می‌سازد. برای ویدیو حرفه‌ای‌تر، از Canva یا Adobe After Effects استفاده کنید.

### **گزینه 3: استخدام فریلنسر**

اگر زمان یا مهارت لازم را ندارید:
1. فایل `docs/video_script_introduction.md` را به فریلنسر بدهید
2. پالت رنگ و لوگو را در اختیارش قرار دهید
3. از او بخواهید ویدیو را مطابق با اسکریپت بسازد

## 📋 محتوای ویدیو

ویدیو شامل 6 بخش است:

1. **معرفی (0-5s)**: نام وب‌سایت و جلب توجه
2. **ویژگی اصلی (5-12s)**: تحلیل هوشمند با AI
3. **بک‌تست (12-20s)**: تست با داده‌های واقعی
4. **بهینه‌سازی (20-28s)**: معاملات خودکار 24/7
5. **فراخوان به عمل (28-35s)**: حساب دمو رایگان
6. **پایان (35-40s)**: نام و URL وب‌سایت
