# 📹 ویدیو معرفی وب‌سایت

این پوشه شامل تمام فایل‌های مربوط به ساخت ویدیو معرفی وب‌سایت **Smart AI Trading Strategy Optimizer** است.

---

## 📁 فایل‌های موجود

### 1. **`video_script_introduction.md`**
اسکریپت کامل ویدیو شامل:
- ساختار دقیق هر بخش (30-40 ثانیه)
- متن‌های روی صفحه
- راهنمای انیمیشن‌ها
- پالت رنگ برند
- راهنمای موسیقی و صداگذاری

### 2. **`video_creation_guide.md`**
راهنمای جامع ساخت ویدیو با 4 روش مختلف:
- استفاده از اسکریپت Python
- استفاده از Canva Pro
- استفاده از Adobe After Effects
- استخدام فریلنسر

### 3. **`../scripts/create_intro_video.py`**
اسکریپت Python برای ساخت خودکار ویدیو پایه

---

## 🚀 شروع سریع

### روش 1: استفاده از اسکریپت Python (ساده)

```bash
# نصب وابستگی‌ها
pip install -r scripts/requirements_video.txt

# اجرای اسکریپت
cd scripts
python create_intro_video.py
```

ویدیو در `frontend/public/pro_vid.mp4` ذخیره می‌شود.

### روش 2: استفاده از Canva (توصیه می‌شود)

1. باز کردن Canva Pro
2. ایجاد پروژه جدید (1920x1080)
3. استفاده از اسکریپت در `video_script_introduction.md`
4. دانلود و ذخیره در `frontend/public/pro_vid.mp4`
